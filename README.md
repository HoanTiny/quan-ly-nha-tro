# Tro FullStack

Web application quan ly chi tieu nha tro voi kien truc tach rieng:

- `FE/`: Next.js App Router, TailwindCSS, UI shell cho admin/member.
- `BE/`: NestJS-style REST API, Prisma schema, modules cho billing va notifications.

## Muc tieu MVP

- Quan ly nha tro, phong, thanh vien
- Tao va chia chi phi theo thang
- Tong hop cong no cuoi ky
- Thanh toan bang QR/manual proof
- Gui nhac dong tien
